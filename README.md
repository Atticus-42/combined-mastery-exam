# Combined Mastery Exam

A free, browser-based comprehensive examination across four Philippine Army lessons: ISR Operations, Armor Operations, Field Artillery Operations and Army Operations. Students enter a name, confirm that they have studied all four lessons, and take a 30-question Easy, Medium, or Hard examination at https://atticus-42.github.io/combined-mastery-exam/. The header links back to all quizzes at https://atticus-42.github.io/quiz-hub/.

## How an attempt is drawn

Each difficulty bank holds 100 questions: the 25 questions of that difficulty from each of the four lesson quizzes. Every attempt (and every retake) draws a fresh selection of 30:

1. The per-lesson counts 8, 8, 7 and 7 are dealt to the four lessons at random.
2. Each lesson's share is drawn at random from its 25 questions.
3. All 30 are shuffled together (Fisher-Yates). Option order is never changed.

`sampleQuestions(bank, random)` takes an injectable random function so the verifier can check draws exactly. Results show the score out of 30, the mastery band (90/75/60%) and a lesson analysis, so students see strengths and gaps by lesson.

## Question banks

`src/questions/{easy,medium,hard}.json` are generated by `scripts/merge-banks.mjs` from the sibling lesson repositories (`../isr-mastery-quiz`, `../armor-mastery-quiz`, `../field-artillery-mastery-quiz`, `../publish-site`), which it only reads. Questions are numbered 1-100 in lesson order; `category` and `lesson` both carry the lesson name and the original tags are kept. Slide and page numbers only make sense inside their own lesson, so `sourceSlides` is removed and the reference is appended to the explanation instead, for example "(Armor Operations, page 31)" or "(ISR Operations, slide 52)". Army Operations has no numbered references. After a lesson bank changes, regenerate and re-verify:

```sh
node scripts/merge-banks.mjs && node scripts/build.mjs && node scripts/verify.mjs
```

## Privacy and class history

No login, payment, analytics, cookies, advertising, external fonts, images, scripts or runtime libraries. Answers stay in browser memory. Only the name, difficulty, score (out of 30), percentage, band and finish time are sent to the class history Google Sheet (tab "Combined Exam History", lesson key `combined`) through `HISTORY_ENDPOINT` in `src/template.html`. `apps-script/Code.gs` is the shared history web app (one spreadsheet, one tab per lesson; it scores `combined` out of 30). The deployed web app must run this version of `Code.gs`, or combined attempts are rejected as an unknown lesson.

## Build and test

`src/template.html` is the page source and `scripts/build.mjs` validates the banks (100 per difficulty, 25 per lesson) and produces the self-contained `index.html`. Test gate:

```sh
node scripts/build.mjs && node scripts/verify.mjs
```
